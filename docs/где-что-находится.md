# Карта проекта: где что находится

Документ отвечает на вопрос «что лежит в каком файле». Проект состоит из двух независимых
реализаций одной и той же лабораторной работы: C++ (в корне) и Go (в папке `go/`).

## Общая структура

```
laba3-main/
  Makefile                 сборка C++ и переход к целям Go
  include/ds/              C++: объявления (заголовки, *.hpp)
  src/                     C++: реализации (*.cpp)
  tests/                   C++: тесты на трех фреймворках
  bench/                   C++: бенчмарк
  docs/                    этот документ и документы про теорию и запуск
  go/                      Go: отдельная реализация
```

Правило для C++: у каждой структуры два файла — **объявление** в `include/ds/*.hpp` и
**реализация** в `src/*.cpp`. В заголовке описан класс и его методы, в `.cpp` — их код.

Правило для Go: у каждой структуры **один** файл `go/ds/*.go`; тесты к нему лежат рядом
в файле `*_test.go`.

## C++: заголовки (include/ds)

| Файл | Что внутри |
|------|-----------|
| `istorable.hpp` | Интерфейс `IStorable` — общий предок всех структур |
| `common.hpp` | Общие функции: ошибки, разбор строки на токены, работа со строками и числами |
| `hashfn.hpp` | Три хеш-функции строк: djb2, fnv1a, sdbm |
| `array.hpp` | Класс `Array` — динамический массив строк |
| `singly_list.hpp` | Класс `SinglyList` — односвязный список |
| `doubly_list.hpp` | Класс `DoublyList` — двусвязный список |
| `stack.hpp` | Класс `Stack` — стек поверх односвязного списка |
| `queue.hpp` | Класс `Queue` — очередь поверх односвязного списка |
| `hashtable.hpp` | Класс `HashTable` — хеш-таблица с открытой адресацией |
| `complete_tree.hpp` | Класс `CompleteTree` — полное двоичное дерево |
| `serializer.hpp` | Класс `Serializer` — сохранение/чтение структур |
| `factory.hpp` | Класс `Factory` — создание структуры по букве типа |

## C++: реализации (src)

| Файл | Что внутри |
|------|-----------|
| `common.cpp` | Код общих функций из `common.hpp` |
| `array.cpp` | Методы `Array`: insert, push, get, set, erase, dump, load, show |
| `singly_list.cpp` | Методы `SinglyList` и работа с узлами |
| `doubly_list.cpp` | Методы `DoublyList` и работа с узлами |
| `stack.cpp` | Методы `Stack` |
| `queue.cpp` | Методы `Queue` |
| `hashtable.cpp` | Вся логика хеш-таблицы: пробы, рехеш, надгробия |
| `complete_tree.cpp` | Дерево: вставка, обходы, проверка полноты, запись/чтение |
| `serializer.cpp` | Текстовый и бинарный форматы сохранения/чтения |
| `factory.cpp` | Соответствие «буква типа -> структура» |

Отдельные реализации не нужны для `hashfn.hpp`, `istorable.hpp` и всех заголовков структур —
это заголовочные или интерфейсные файлы.

## C++: тесты и бенчмарк

| Файл | Что внутри |
|------|-----------|
| `tests/test_utils.hpp` | Общие мелочи для тестов (например, помощник `S({...})`) |
| `tests/test_gtest.cpp` | Тесты на GoogleTest |
| `tests/test_catch2.cpp` | Тесты на Catch2 |
| `tests/test_boost.cpp` | Тесты на Boost.Test |
| `bench/benchmark.cpp` | Замер времени операций при N = 1000, 4000, 16000 |

Три файла тестов проверяют одно и то же, но каждый на своем фреймворке — чтобы показать, что тесты
не зависят от конкретной библиотеки.

## Корневой Makefile

Файл `Makefile` в корне собирает C++ и перенаправляет Go-цели в подпроект `go/`.
Список целей и как ими пользоваться — в документе «как это всё запускается» (`docs/как-запускать.md`).
